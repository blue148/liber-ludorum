Mobile-first redesign planned March 2026. User priorities are:
1. Pick a game for game night → Game Chooser (currently 2 taps deep)
2. Choose a first player → First Player Chooser (currently 2 taps deep)
3. What were the last games I won (no explicit win tracking; closest is Most Played / play history)
4. Add a new game to catalogue → New Entry button in Library
5. Remember a game to buy → Wishlist sub-tab in Library
6. Favorite game by play count → Most Played Games on Dashboard

**Why:** Most users access on iPhone 16 or iPad. Current nav is top horizontal tabs, small touch targets, Game Night tools require 2 navigation steps.

**How to apply:** Design changes should use bottom nav on mobile, FAB for add-game, surface Game Night tools in 1 tap, keep desktop experience as-is (not a mobile-UI-in-a-browser).
